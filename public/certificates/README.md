# Certificate photos

Put photos directly inside the folder for each certificate. Use JPG, JPEG, PNG, WebP, AVIF, or GIF. For PDFs, save image previews alongside the source files. The original PDFs can stay in their folders. Name images `01.jpg`, `02.jpg`, and so on to control their display order. Refresh the local page after adding files, and include the images in the next production build when publishing.

The existing folders with descriptive names also work. Use the folder names below when creating new folders.
